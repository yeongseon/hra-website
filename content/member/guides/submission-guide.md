# 보고서 제출 안내

본 문서는 보고서 양식을 활용한 **작성본 확인 → PDF 변환 → 제출 준비**를 안내합니다. 제출 경로와 마감은 해당 기수·과제의 공지를 먼저 확인하세요. 아래 기본 안내를 개인 과제의 제출 조건으로 그대로 적용하지 않습니다.

`내 과제`를 통해 개인 과제를 제출하도록 안내받았다면 그 화면의 파일 조건·마감·최종 제출 결과를 확인하세요. 자료실에 파일을 올리거나 양식을 PDF로 저장한 것만으로 개인 과제 제출이 완료되지는 않습니다.

## 1. 전체 흐름

1. [보고서 양식](/resources)에서 분야별 양식 선택
2. Markdown 본문 작성 (참고: [Markdown 문법 가이드](/member/guides/markdown-guide))
3. 조원 검토 및 지도교수 컨펌
4. 작성한 본문을 사용한 문서 편집기에서 PDF로 내보내고 내용 확인
5. 파일명 규칙에 맞게 파일명 변경
6. 지정된 경로로 제출

## 2. 양식 PDF와 작성본 PDF 구분

1. [보고서 양식 목록](/resources) 페이지 접속
2. 작성한 분야의 양식 상세 페이지 진입
3. 우측 상단 **"PDF로 저장"** 버튼 클릭
4. 브라우저 인쇄 대화상자가 자동으로 열립니다.
5. **대상**을 `PDF로 저장`으로 선택 후 저장

위 방법은 사이트에 표시된 **양식 미리보기**를 PDF로 저장합니다. 작성한 본문을 사이트가 자동으로 채워 주는 기능은 아닙니다. 제출할 작성본은 사용한 편집기에서 별도로 내보내세요.

저장 전에 인쇄 미리보기에서 A4 용지, 여백, 쪽 나눔, 이미지 표시를 확인합니다. 브라우저 설정에 따라 출력 결과가 달라질 수 있습니다.

## 3. 파일명 규칙

PDF 파일명은 다음 형식을 따릅니다.

```
HRA{기수}_{조}_{분야}_{주제}.pdf
```

### 가. 분야 코드

| 분야 | 코드 |
| --- | --- |
| 경영서 | `경영서` |
| 고전명작 | `고전명작` |
| 기업실무·한국경제사 | `기업실무` |

### 나. 작성 예시

| 상황 | 파일명 |
| --- | --- |
| 19기 1조, 경영서, 『기업가정신』 | `HRA19_1조_경영서_기업가정신.pdf` |
| 19기 3조, 고전명작, 『논어』 | `HRA19_3조_고전명작_논어.pdf` |
| 20기 2조, 기업실무, 삼성전자 사례 | `HRA20_2조_기업실무_삼성전자사례.pdf` |

### 다. 작성 규칙

- 기수 번호는 숫자만 (`19`, `20`)
- 조 번호 뒤에는 반드시 `조` 표기 (`1조`, `2조`)
- 분야 코드는 위 표 그대로
- 위 예시처럼 주제를 간단히 적고 구분용 언더스코어(`_`)와 혼동할 문자는 피합니다. 별도 공지된 파일명 규칙이 있으면 그 안내를 따릅니다.
- 특수문자(`/ \ : * ? " < > |`) 사용 금지

## 4. 제출 경로 확인

| 제출 항목 | 경로 |
| --- | --- |
| PDF 본 | 해당 기수에서 이메일·공용 드라이브 제출을 안내한 경우 그 경로 사용 |
| Markdown 원본 | 기수에서 원본 제출·백업을 요청한 경우 지정 경로 사용 |
| 발표 자료 (선택) | 별도 슬라이드 파일 첨부 가능 |

> 정확한 제출 이메일·드라이브 주소 또는 개인 과제 제출 방법은 운영팀의 해당 기수 공지에서 확인합니다. 안내받지 않은 공개 저장소에 보고서를 올리지 않습니다.

## 5. 제출 마감 확인

아래는 기존 보고서 준비 안내입니다. 실제 마감과 검토 일정은 기수·과제 공지를 우선하며, 개인 과제 화면에 표시된 마감을 이 안내로 변경하지 않습니다.

- **1차 검토본**: 발표 1주 전까지 지도교수 송부
- **최종본**: 발표일 당일 오전까지 운영팀 송부
- 마감 후 제출은 불가하며, 부득이한 경우 운영팀에 사전 연락 필수

## 6. 검토 체크리스트

- [ ] 발표 정보 표 모든 항목 작성 완료
- [ ] 5장 목차 누락 없음
- [ ] 출처·참고자료 명시
- [ ] 맞춤법 검사 완료
- [ ] PDF 변환 결과 깨짐 없음 확인
- [ ] 파일명 규칙 준수
- [ ] 지도교수 컨펌 완료

## 7. 자주 묻는 질문

**Q. PDF에 여백이 너무 좁거나 넓게 나옵니다.**
브라우저의 인쇄 미리보기에서 "여백: 기본"을 선택하세요. 시스템에서 A4 표준 여백을 적용합니다.

**Q. 한글 글꼴이 깨집니다.**
화면의 글꼴이 로드된 뒤 인쇄 미리보기를 다시 열어 보세요. 사용한 편집기의 글꼴 포함 설정도 확인합니다. "배경 그래픽" 옵션은 배경 출력 설정이며 한글 글꼴 표시를 보장하는 설정은 아닙니다.

**Q. 표가 한 페이지에 안 들어갑니다.**
표가 너무 길면 두 개로 분할하거나, 셀 안의 긴 텍스트는 줄바꿈(`<br>`)으로 정리하세요.

**Q. 이미지가 PDF에 누락됩니다.**
화면과 인쇄 미리보기에서 이미지가 모두 표시되는지 확인하세요. 허용된 출처와 지원하는 업로드 방법을 사용하고, 표시되지 않으면 담당자에게 문의하세요.

**Q. 제출 후 수정이 필요합니다.**
운영팀에 즉시 연락하여 재제출 가능 여부를 확인하세요. 발표 후 수정은 원칙적으로 불가합니다.
