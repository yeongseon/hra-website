# 지원서 질문 저장과 제출의 동시성 정책

질문·선택지 저장은 `save_application_form_questions` 단일 PostgreSQL 함수로 처리한다. 함수는 `application_forms` 행을 `FOR UPDATE`로 잠그고 `questions_revision`이 관리자 화면에서 읽은 값과 같은지 확인한다. 오래된 화면의 저장은 거부한다. 질문·선택지 변경과 버전 증가는 한 문장으로 확정되므로 중간 실패가 이전 내용을 바꾸지 않는다.

지원서 제출은 커밋된 질문·선택지만 한 번의 양식 조회로 읽는다. 저장 중에는 이전 질문·선택지 전체를 읽고, 저장 후에는 새 내용 전체를 읽는다. 제출 마스터의 양식 외래키는 저장 중의 양식 행 잠금이 풀릴 때까지 대기한다. 제출자가 이전 선택지를 읽고 저장이 끝난 뒤 답변을 쓰는 경우, 그 값은 제출 시 검증한 값으로 보존된다. 그 사이 질문이 삭제됐다면 답변 외래키가 제출을 거부한다. 이때 제출 마스터·답변의 완전한 원자성은 #97에서 처리한다.

배포 순서는 `npm run db:migrate-atomic-application-questions` 실행 후 애플리케이션 배포다. 이 마이그레이션은 기존 질문·답변을 변경하지 않고 버전 컬럼과 저장 함수만 추가한다.
