# 모집 일정과 지원서 접수 정책 (#104, #114)

## 내부 지원서

내부 지원서의 접수 가능 여부는 해당 양식의 `application_forms.is_published`가 결정한다. 관리자에게 양식을 공개·비공개로 바꿀 수 있는 독립 스위치가 있으며, 서버 제출 액션도 제출 시점에 이 값을 다시 검사한다. 모집안내의 날짜, 모집 상태 배지, 현재 모집 기수, 외부 구글폼 URL은 내부 제출을 자동으로 열거나 닫지 않는다.

| 상황 | 내부 양식 제출 |
| --- | --- |
| 양식 비공개 | 거부. 목록·상세에서도 접수 양식으로 제공하지 않음 |
| 양식 공개, 모집 시작일 전 | 허용. 미리 공개한 양식은 직접 링크에서도 접수됨 |
| 양식 공개, 모집 종료일 후 | 허용. 추가모집·상시접수·기존 양식 연장을 위한 수동 제어 |
| 일정이 비어 있음 | 양식 공개 여부만 적용 |

운영자는 내부 접수를 마칠 때 반드시 해당 양식을 비공개로 바꾼다. 날짜만 지나도 자동 마감되는 정책을 도입하려면 별도 요구사항으로 결정한다. 양식에 기수가 연결되지 않은 경우도 공개 여부가 접수 스위치이며, 기수별 모집 일정에서 값을 추측하지 않는다.

## 모집안내와 외부 구글폼

모집안내 배지와 외부 구글폼 버튼은 모집 설정의 시작일·종료일로 계산한다. 한국 시간(`Asia/Seoul`)의 달력 날짜를 사용하며 **시작일 00:00부터 종료일 23:59:59.999까지** `모집중`이다. 종료일 다음 날 00:00에 `마감`으로 바뀐다. 시작일이 종료일보다 늦은 값은 관리자 저장 단계에서 거부한다.

| 시작일 | 종료일 | 안내 상태 |
| --- | --- | --- |
| 미래 날짜 | 설정됨 또는 없음 | 예정 |
| 오늘 이전/오늘 | 오늘 이후/오늘 | 모집중 |
| 오늘 이전/오늘 | 없음 | 모집중: 상시 안내 가능 |
| 없음 | 미래 날짜 | 예정: 자동으로 열지 않음 |
| 없음 | 없음 | 예정 |
| 무관 | 어제 이전 | 마감 |

외부 구글폼 버튼은 `모집중`이고 URL이 있을 때만 사이트에 표시된다. 버튼이 숨겨져도 이미 공유된 구글폼 직접 URL의 제출을 이 사이트가 막을 수는 없다. 외부 접수 종료·추가모집·상시접수는 구글폼 자체의 설정도 운영자가 관리한다. 내부 양식은 별도 공개 스위치를 사용하므로 외부 버튼의 노출과 독립적으로 접수할 수 있다.

저장된 `recruitment_status` 컬럼은 현재 모집안내의 상태 계산이나 내부 제출 허용에 사용하지 않는다. 화면은 날짜로 상태를 계산하고, 내부 제출은 양식 공개 여부로 검사한다. `tests/unit/recruitment-status.test.ts`는 KST 자정 전후, 비어 있는 일정, 시작일·종료일 역전 저장을 검증한다.
