# 기존 카카오 계정 바인딩 복구 (#174)

#67에서 이메일 일치만으로 소셜 계정을 자동 연결하던 경로를 차단한 뒤, 과거 카카오 가입 계정 중 바인딩이 비어 있는 계정은 재로그인이 거부됩니다. 과거 로그인 코드는 카카오가 이메일을 제공하지 않을 때 `kakao_<카카오 사용자 ID>@oauth.placeholder`를 생성했습니다. 이 형식은 당시 인증된 카카오 응답의 사용자 ID로 만들어졌습니다.

`scripts/migrate-backfill-kakao-legacy-bindings.mjs`는 비밀번호와 바인딩 두 필드가 모두 비어 있고 위 형식과 정확히 일치하는 계정만 복원합니다. 일반 이메일 계정이나 다른 소셜 제공자는 자동 연결하지 않습니다.

## 실행과 확인

1. 운영 DB 백업과 연결 대상을 확인하고 읽기 전용 점검을 실행합니다: `node --env-file=.env scripts/migrate-backfill-kakao-legacy-bindings.mjs`.
2. 출력된 건수를 검토한 뒤 `node --env-file=.env scripts/migrate-backfill-kakao-legacy-bindings.mjs --apply --expect=<확인한 건수>`를 실행합니다. 스크립트는 중복·충돌·건수를 다시 확인하고 한 PostgreSQL 문장으로 갱신합니다. 오류가 나면 문장 전체가 롤백됩니다.
3. 재실행해 미연결 계정이 0개인지 확인하고, 실제 기존 카카오 계정으로 로그인을 검증합니다.

적용 직전에 복구용 계정 ID와 이전 바인딩 상태만 제한 권한의 로컬 임시 파일에 저장합니다. 이메일과 이름은 기록하지 않습니다. 파일은 실제 로그인 확인과 운영 기록 후 안전하게 정리합니다.

2026-10-13 운영 적용에서는 정확한 형식의 미연결 카카오 계정 10개를 복원했고, 사후 읽기 전용 점검에서 0개를 확인했습니다. 기존 카카오 사용자 로그인도 확인했습니다.
