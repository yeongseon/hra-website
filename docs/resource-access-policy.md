# 자료실 공동 자료 접근 정책 (#100)

주차별 텍스트와 수업일지는 학생별 과제 제출물이 아니라 기수별 공동 자료다. 승인된 내부 회원은 본인 기수, 다른 기수, 기수 미지정(`cohortId = null`) 자료를 모두 열람할 수 있다. 기수별 목록의 필터는 탐색 편의 기능이며 서버 인가 경계가 아니다. 통합 목록·상세·인쇄에도 같은 열람 정책을 적용한다.

| 역할 | 본인 기수 열람 | 다른 기수 열람 | 공통 자료 열람 | 주차별 텍스트·수업일지 작성 | 강의자료 |
| --- | --- | --- | --- | --- | --- |
| ADMIN | 가능 | 가능 | 가능 | 모든 기수·공통 자료 작성 가능 | 학생용·교수용 열람·업로드 가능 |
| FACULTY | 가능 | 가능 | 가능 | 모든 기수·공통 자료 작성 가능 | 학생용·교수용 열람·업로드 가능 |
| MEMBER | 가능 | 가능 | 가능 | DB에 등록된 본인 기수에만 작성 가능 | 학생용만 열람 가능 |
| PENDING | 불가 | 불가 | 불가 | 불가 | 불가 |

기수가 없는 MEMBER도 공동 자료는 읽을 수 있지만 기수별 글을 작성할 수 없다. 승인 대기 계정은 자료실 DB 조회 전에 차단한다. 파일 URL 자체의 접근 통제는 별도 #101에서 다룬다.
