# 자료실 공동 자료 접근 정책 (#100)

이 문서는 **누가 어떤 공동 자료를 읽고 작성할 수 있는지** 정합니다. 주차별 텍스트와 수업일지는 학생별 과제 제출물이 아니라 기수별 공동 자료입니다. 개인 과제와 학적의 권한은 별도 [학사 문서](ACADEMIC-MANAGEMENT-ROADMAP.md)를 따릅니다.

## 열람과 작성은 다른 권한입니다

승인된 내부 회원은 본인 기수, 다른 기수, 기수 미지정(`cohortId = null`) 자료를 모두 열람할 수 있습니다. 기수별 목록의 필터는 자료를 찾아보기 위한 기능입니다. 서버가 접근을 허용할지 결정하는 **인가** 규칙은 아래 표를 따릅니다. 통합 목록·상세·인쇄에도 같은 열람 정책을 적용합니다.

| 역할 | 본인 기수 열람 | 다른 기수 열람 | 공통 자료 열람 | 주차별 텍스트·수업일지 작성 | 강의자료 |
| --- | --- | --- | --- | --- | --- |
| ADMIN | 가능 | 가능 | 가능 | 모든 기수·공통 자료 작성 가능 | 학생용·교수용 열람·업로드 가능 |
| FACULTY | 가능 | 가능 | 가능 | 모든 기수·공통 자료 작성 가능 | 학생용·교수용 열람·업로드 가능 |
| MEMBER | 가능 | 가능 | 가능 | DB에 등록된 본인 기수에만 작성 가능 | 학생용만 열람 가능 |
| PENDING | 불가 | 불가 | 불가 | 불가 | 불가 |

예를 들어 1기 MEMBER가 2기의 공동 일지를 읽는 것은 허용된 동작입니다. 작성할 때에는 현재 DB에 배정된 본인 기수를 사용합니다. 브라우저의 기수 선택만 바꿔 다른 기수에 작성할 권한을 얻는 것은 아닙니다.

기수가 없는 MEMBER도 공동 자료는 읽을 수 있지만 기수별 글을 작성할 수 없습니다. 승인 대기 계정은 자료실 DB 조회 전에 차단합니다.

## 운영자가 확인할 순서

1. 읽기 문제인지 작성 문제인지 구분합니다.
2. [회원 관리](ADMIN-GUIDE.md)에서 현재 역할과 기수 배정을 확인합니다.
3. 변경 후 새 로그인에서 허용 범위를 확인합니다. 역할과 기수는 자료실 필터가 아니라 회원 정보에서 관리합니다.
4. 파일만 열리지 않으면 [자료실 파일 접근 정책](resource-file-access-policy.md)의 저장소·파일 전달 조건을 확인합니다.

**정상 결과:** 승인 회원은 모든 공동 자료를 읽고, 작성과 교수용 강의자료는 위 표대로 제한됩니다. **결과가 다르면:** 사용 역할·기수·기능·발생 시각을 남기고 담당자가 서버 권한 조건을 확인합니다. 실제 파일 URL이나 회원 개인정보를 공개 기록에 남기지 않습니다.
