# HRA 홈페이지 관리자 가이드

홈페이지 운영자가 콘텐츠와 회원을 관리하는 방법입니다. DB나 저장소 콘솔에서 직접 수정하는 작업은 개발·운영 담당자의 절차로 분리합니다. 메뉴와 용어를 먼저 익히고, 저장 후 실제 화면에서 결과를 확인하세요.

문서 확인일: 2026-10-18. 앱 기능과 실제 운영 설정은 다를 수 있습니다. 홈페이지 관리자와 학사 운영 책임자는 별도로 지정됩니다.

## 1. 로그인과 화면 확인

1. 이메일·비밀번호 계정은 `/admin/login`, 설정된 소셜 계정은 `/login`으로 이동합니다.
2. 준비된 관리자 계정의 로그인 방식을 사용합니다. `/login`에는 이메일·비밀번호 입력 폼이 없습니다.
3. `/admin`에서 대시보드와 관리자 메뉴를 확인합니다.

처음부터 관리자 계정이 없는 새 환경은 [최초 관리자 준비](DATABASE.md)를 담당자가 먼저 수행합니다. 소셜 로그인 버튼이 보이지 않으면 해당 제공자가 설정되지 않았을 수 있습니다.

**정상 결과:** 관리 메뉴가 표시됩니다. **접근이 거부되면:** 현재 계정과 부여받은 역할을 확인합니다. 학사 화면의 권한을 얻으려고 홈페이지 관리자 역할을 임의로 바꾸지 않습니다.

## 2. 무엇을 어디에서 바꾸나요?

| 메뉴·주소 | 관리할 내용 |
| --- | --- |
| 교수진 `/admin/faculty` | 공개 교수 소개·사진 |
| 기수 관리 `/admin/recruitment` | 기수 정보 |
| 모집 설정 `/admin/recruitment-settings` | 현재 모집 안내·일정·포스터·외부 접수 링크 |
| 지원서 관리 `/admin/application-forms` | 내장 지원서 양식·질문·제출 결과 |
| 공지사항 `/admin/notices` | 공지 본문·공개 상태 |
| 언론보도 `/admin/press` | 기사 소개·원문 링크 |
| 갤러리 `/admin/gallery` | 앨범·활동 사진 |
| 수료생 이야기 `/admin/alumni` | 소개·사진 |
| FAQ `/admin/faq` | 질문과 연락 안내 |
| 일정 관리 `/admin/schedule` | 수업·행사 일정 |
| 자료실 `/admin/resources` | 공동 자료·양식·첨부 |
| 회원 관리 `/admin/users` | 회원 그룹·기수·계정 관리 |

대시보드의 숫자는 각 데이터의 현황입니다. 로그인·업로드·DB의 운영 상태를 모두 검사하는 지표는 아닙니다.

## 3. 글과 사진을 등록하는 공통 순서

1. 관리할 메뉴에서 새 항목을 엽니다.
2. 제목·본문·날짜 등 필요한 항목을 채우고 파일을 선택합니다.
3. 화면의 미리보기에서 내용·줄바꿈·이미지를 확인합니다.
4. 저장하고 목록 또는 상세에서 결과를 확인합니다.
5. 공개 콘텐츠라면 실제 공개 페이지에서도 확인합니다.

공지와 소개 본문은 DB에 저장되고 파일은 Blob에 저장됩니다. 관리자 화면에서 저장하는 콘텐츠를 바꾸기 위해 GitHub 소스까지 수정할 필요는 없습니다.

파일 업로드가 진행 중이면 저장 성공 안내가 나올 때까지 기다립니다. 화면이 끊겨 결과를 모를 때는 먼저 목록을 새로고침해 저장 여부를 확인하세요. 같은 파일을 반복 선택하거나 저장소 콘솔에서 임의 삭제하지 않습니다. 허용 파일 종류와 크기는 해당 입력 화면을 따릅니다.

조회수는 참고 지표입니다. 페이지를 열 때마다 모든 요청이 반드시 한 번씩 집계된다고 운영 결과를 보증하지 않습니다.

## 4. 자료실: 읽기 권한과 작성 권한

주차별 텍스트·수업일지는 **기수별 공동 자료**입니다. 학생의 개인 과제 제출과 다릅니다.

| 계정 | 공동 자료 열람 | 텍스트·일지 작성 | 강의자료 |
| --- | --- | --- | --- |
| ADMIN | 모든 기수·공통 자료 | 모든 기수·공통 자료 | 학생용·교수용 열람/업로드 |
| FACULTY | 모든 기수·공통 자료 | 모든 기수·공통 자료 | 학생용·교수용 열람/업로드 |
| MEMBER | 모든 기수·공통 자료 | DB에 배정된 본인 기수 | 학생용 열람 |
| PENDING | 불가 | 불가 | 불가 |

기수 선택 필터는 목록을 좁혀 보는 기능입니다. 다른 기수 자료가 보인다는 이유만으로 잘못된 권한이라고 판단하지 않습니다. 반대로 기수가 없는 MEMBER는 읽을 수 있어도 기수별 글은 작성할 수 없습니다.

자료를 올릴 때에는 대상이 학생용인지 교수용인지 확인하고, 보호 자료는 해당 자료실 첨부 기능을 사용합니다. 공개 페이지용 이미지나 외부 공유 URL을 넣는다고 그 파일이 비공개 첨부로 바뀌지는 않습니다. 실제 보호 자료 저장소 전환과 파일 검증은 담당자가 [파일 접근 정책](resource-file-access-policy.md)에 따라 확인합니다.

PDF 미리보기와 일반 다운로드는 자료 권한을 확인하는 경로를 사용합니다. Office 문서는 외부 뷰어에 보호 자료 주소를 전달하지 않고 내려받아 확인합니다.

## 5. 모집을 열고 닫는 두 가지 방식

모집 안내와 내부 지원서에는 **서로 다른 접수 스위치**가 있습니다.

| 운영할 대상 | 여는 방법 | 닫는 방법 |
| --- | --- | --- |
| 내장 지원서 | 지원서 관리에서 양식 공개 | 해당 양식을 비공개로 변경 |
| 모집안내의 외부 접수 버튼 | 모집 설정의 날짜와 외부 URL 확인 | 안내 날짜 조정, 외부 서비스에서도 접수 종료 |

모집 날짜가 지났다고 내장 지원서가 자동 마감되지 않습니다. 내장 양식은 공개 여부를 기준으로 접수합니다. 외부 버튼은 한국 시간의 모집 시작일·종료일로 표시되지만, 사이트에서 버튼이 사라져도 외부 서비스의 직접 링크는 별도로 관리해야 합니다.

포스터·현재 모집 정보·세부 안내는 각 섹션에서 저장합니다. 다른 운영자가 내용을 바꾼 상태라면 저장 결과를 확인하고 필요할 때 새로고침해 다시 검토합니다. 상세 규칙은 [모집 일정과 접수 정책](recruitment-intake-policy.md)을 참고하세요.

## 6. 내부 지원서 확인과 양식 편집

`/admin/application-forms`에서 양식을 만들고 질문을 설정한 뒤 공개합니다. 제출 내역의 상태를 확인하고, 필요한 경우 제공되는 CSV 내보내기를 사용합니다. 내장 지원서 데이터는 DB에 저장하며 `GOOGLE_SHEETS_API_KEY`를 요구하지 않습니다.

이미 답변이 달린 질문은 과거 답변의 뜻을 보존하기 위해 제목·유형·선택지 등의 변경이 제한됩니다. 새로운 질문이 필요하면 새 항목으로 추가합니다. 오래 열어 둔 화면의 저장이 거부되면 자신의 입력을 보존하고 새로고침한 다음 최신 질문과 비교합니다. [동시 편집 정책](application-form-concurrency.md)에 이유와 처리 방법을 설명했습니다.

CSV에는 지원자 정보가 포함될 수 있으므로 필요한 담당자에게 승인된 방식으로 전달합니다.

## 7. 회원 승인·그룹 변경·삭제

현재 회원 역할은 네 가지입니다. `PENDING`은 승인 대기, `MEMBER`는 승인 회원, `FACULTY`는 교수, `ADMIN`은 홈페이지 관리자입니다.

회원 관리의 그룹 선택에서는 관리 역할과 기수를 구분합니다. **기수를 선택하면 MEMBER 역할과 그 기수가 함께 설정**됩니다. ADMIN/FACULTY/PENDING을 선택하면 기수 연결을 해제하는 현재 동작도 고려해야 합니다. 저장 후 역할·기수 결과를 확인하고 사용자에게 다시 로그인이 필요할 수 있음을 안내합니다.

자기 자신의 그룹 변경·삭제와 마지막 관리자 삭제는 제한됩니다. 학적이나 학사 운영 이력이 연결된 계정도 삭제가 거부될 수 있습니다. 이때 관련 글이나 학적을 먼저 지우는 방식으로 진행하지 말고 담당자에게 보존·계정 정리를 함께 요청합니다.

**출결은 교수의 기본 업무가 아닙니다.** 어드바이저·조교의 배정과 출결 기능은 [학사 로드맵](ACADEMIC-MANAGEMENT-ROADMAP.md)의 별도 단계이며, 홈페이지 ADMIN 권한과 혼동하지 않습니다.

## 8. 문제가 생기면

| 상황 | 확인·다음 행동 |
| --- | --- |
| 신규 회원이 자료실에 못 들어감 | PENDING 여부, 승인된 그룹 확인 |
| 회원이 기수별 글을 못 씀 | 현재 DB에 배정된 기수 확인 |
| 내부 접수가 계속 열림 | 양식의 공개 여부 확인; 모집 날짜만으로 마감되지 않음 |
| 질문 저장이 거부됨 | 답변 존재 또는 다른 편집자의 변경 여부 확인 후 최신 화면 비교 |
| 파일 저장 결과가 불명확함 | 목록에서 저장 여부를 먼저 확인한 뒤 재시도 |
| 보호 자료를 열 수 없음 | 계정 권한과 담당자의 저장소 전환·설정 확인 |
| 관리자 비밀번호 분실 | 계정 복구 담당자에게 요청; seed-admin은 기존 관리자 비밀번호 재설정 도구가 아님 |
| 학사 준비 안내 표시 | 정책·DB·기능 설정의 준비 상태를 학사 담당자에게 확인 |

담당자에게는 발생 시각, 사용 메뉴, 보인 오류, 저장 여부를 전달합니다. 비밀번호·파일 원본 주소·지원자 정보가 포함된 화면은 그대로 공개하지 않습니다. 환경 설정 문제의 다음 단계는 [배포 가이드](DEPLOYMENT.md)에 있습니다.
